# Ferry releases

Signed install files for **Ferry**, a personal app for sharing files between my own devices.

This repository holds release files only. The source code is private.

- **Ferry**: stable releases.
- **Ferry Beta**: pre-releases, marked as such.

Ferry checks this page for updates on its own. You don't need to download anything here by hand.
Every Android file is signed with the same key, and every Mac update is signed, so a file that didn't come from me will be rejected.
